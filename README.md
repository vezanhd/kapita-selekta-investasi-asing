# Pengaruh Investasi Asing terhadap Tingkat Pengangguran di Indonesia

**Kapita Selekta** | Teknik Informatika | Universitas Lampung | 2024

### Tentang Project
Proyek ini menganalisis hubungan antara Investasi Asing (Foreign Direct Investment) dengan tingkat pengangguran di Indonesia periode 2019–2023 menggunakan data resmi dari BPS.

### Peran Saya
- **Ketua Kelompok**
- **Lead Dashboard Developer** (merancang dan membangun sebagian besar visualisasi Tableau)

### Fitur Dashboard
- Peta choropleth per provinsi
- Analisis Time Series tren investasi dan penyerapan tenaga kerja
- Filter interaktif berdasarkan tahun dan provinsi
- Visualisasi Total Proyek, Total Investasi, dan Persentase Tenaga Kerja

### Tech Stack
- **Tableau Public** (Visualisasi & Dashboard)
- **Microsoft Excel** (Data Cleaning & Processing)
- Analisis Statistik Deskriptif
